## 建议后期

- 配音语速：约 210–230 字/分钟；
- 背景音乐：轻量科技感，90–105 BPM；
- 操作点击：柔和 UI click；
- 批次生成：短促上升提示音；
- 归档完成：清晰但克制的 success chime；
- 若用于站内引导，可删除配音，只保留屏幕字幕与操作音。
