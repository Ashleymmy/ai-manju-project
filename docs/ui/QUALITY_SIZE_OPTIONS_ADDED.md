# 质量、尺寸和宽高比选项已添加

## 修改内容

已在"关键帧生成"页面添加了图二中有而图一没有的选项。

### 1. 新增功能

#### 质量选项
- **自动** - 自动选择质量
- **高** - 高质量生成
- **中** - 中等质量
- **低** - 低质量（快速）

#### 尺寸设置
- **宽度 (W)** - 256-2048px，可手动输入
- **高度 (H)** - 256-2048px，可手动输入
- **交换按钮 (⇄)** - 快速交换宽高值
- **16倍数对齐** - 勾选后自动对齐到16的倍数

#### 宽高比选项（13种）
```
1:1      3:2      2:3      4:3
3:4      16:9     9:16     1:1(2x)
16:9(2x) 9:16(2x) 16:9(4k) 9:16(4k)
auto
```

### 4. CSS 样式

新增样式类：
- `.composer-size-settings` - 尺寸设置容器
- `.size-inputs` - 尺寸输入框容器
- `.swap-size` - 交换宽高按钮
- `.align-toggle` - 16倍数对齐开关
- `.composer-ratio-grid` - 宽高比网格容器
- `.ratio-grid` - 4列网格布局
- `.ratio-grid button::before` - 宽高比图标（伪元素）

### 5. 功能特性

- ✅ **质量选择** - 4个质量档位（自动/高/中/低）
- ✅ **自定义尺寸** - 手动输入宽高（256-2048px）
- ✅ **快速交换** - 一键交换宽度和高度
- ✅ **16倍对齐** - 自动对齐到GPU友好的尺寸
- ✅ **13种宽高比** - 覆盖常用和高清比例
- ✅ **视觉图标** - 每个宽高比显示直观的形状预览
- ✅ **响应式** - 移动端自动调整为3列布局

### 6. 视觉效果
