# 图片 @ 引用光标修复

## 原因

图片引用在原生 textarea 中由两个隐藏的全角空格占位。旧方向键逻辑只处理光标已经在占位符内部的情况，没有处理边界。右键从引用起点进入中点后，异步 selection 校正又将光标拉回起点，下一次按键重复同一过程。插入和删除还使用延迟 RAF 恢复光标，可能与随后的操作相互干扰。

## 改动

- 左右方向键从引用边界一次跨过整个引用；Shift 扩展/收缩选区也按完整引用处理。
- 插入/删除后在受控文本提交完成时立即恢复光标，去掉延迟 RAF；选择校正只处理当前聚焦的输入框。
- 单击引用缩略图左右两侧将光标放到相应边界，Shift 单击扩展选区；双击查看引用详情。鼠标使用文本光标。
- 原子删除引用和包含引用的选区，避免相同空格占位符导致删除另一张图片。
- 中文输入法组合期间不移动光标、不触发生成；保留输入框原有事件回调。
