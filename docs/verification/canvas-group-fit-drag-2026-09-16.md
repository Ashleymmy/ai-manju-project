# 分组框自适应与整体拖动验收

## 行为

- 分组框根据全部成员节点的实际位置和尺寸重新计算，保留统一边距。节点尺寸改变、生成结果更新、删除成员、加载旧画布及撤销重做都会同步更新分组框。
- 已确认分组中，拖动节点主体、节点标题或分组背景会整体移动全部成员，保持节点间相对位置；批量节点的子节点同步移动。
- 用户明确确认：仅已组成的分组整体拖动，临时框选保持原操作。解绑后恢复独立节点拖动。
- 输入框、功能按钮、媒体播放控件、连线端口继续使用其原有操作。分组四角保留视觉标识，改用自动计算尺寸，不再单独拖大或缩小背景框。
- 拖动结束抑制附带点击，避免松手后又切成单节点选择；一次拖动只记录一次历史。

## 根因与处理

原分组保存独立的固定宽高，不随节点位置/尺寸变化；节点拖动入口也没有检查已确认的组成员关系。

现在在画布数据更新的同一事务中计算分组边界，使显示、连线端点和快照保存使用一致的几何信息。节点拖动入口识别确认分组并进入分组拖动，拖动涉及的节点以集合去重。
