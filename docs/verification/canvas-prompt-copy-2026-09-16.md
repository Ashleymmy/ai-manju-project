# 检查器提示词复制按钮修复

截图定位为检查器右上角“一键复制提示词内容”，与底部“复制节点”操作不同。旧按钮直接调用 `navigator.clipboard.writeText`，没有检测 API 是否存在，也没有处理写入拒绝，因此 HTTP 环境或剪贴板权限受限时会表现为无反应。

修复后使用共享的剪贴板兼容方法：优先异步剪贴板，失败或不可用时尝试兼容复制；完整保留提示词换行和缩进。复制成功显示勾选和提示，空内容或失败给出明确反馈。复制期间防止重复调用，并保留焦点。右键菜单的提示词复制同步使用相同方法与当前编辑内容。

新增真实按钮点击测试，覆盖正常复制、接口缺失、权限拒绝后的兼容复制、彻底失败、空内容、文本变化和焦点恢复。测试曾发现异步复制中禁用按钮导致恢复焦点失败，已通过保留焦点且单独阻止重复点击的方式修复。
