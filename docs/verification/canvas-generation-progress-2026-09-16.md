# 画布生成进度提示调整

## 修改

- 原进度条与圆角加载层互为兄弟节点，贴住卡片底边且缺少裁切，被高层级加载遮罩遮挡。将进度提示纳入加载层，固定在节点内部，四周留出 12px 间距。
- 使用底部半透明圆角提示条，统一显示生成状态、百分比与圆角细进度条，删除右上角重复数字。
- 进度值限制为 0–100；未获得有效进度时显示“正在准备生成”与不定进度动画。减少动态效果设置下关闭进度动画。
- 保留像素加载动画，提示层不截获鼠标事件。
