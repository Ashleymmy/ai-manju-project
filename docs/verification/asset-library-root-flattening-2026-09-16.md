# 资产库去除系统归档显示层级

画布 @ 引用菜单、画布素材选择器和资产库侧栏共用目录展示规则：隐藏后台的 `system_root`，把其直接子目录提升到第一层，保留子目录下原有结构、真实 ID、素材归属及计数。用户自行创建的同名“系统归档”文件夹保持可见。

画布仍按前置节点、当前画布文件夹、收藏夹、系统分类目录、用户目录的顺序展示。资产库移动目录选项及目录路径同步去掉该层；历史折叠状态不会导致提升后的目录消失。

本轮只修改前端展示及相应回归断言，没有修改后台目录或移动素材。
